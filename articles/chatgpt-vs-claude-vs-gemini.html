Compare AI assistants using one task and an answer key

A blank, reproducible comparison procedure for ChatGPT, Claude, Gemini or another assistant; no invented product ranking.

Maintained by ShawnUpdated November 13, 20262 min read

Fictional practice case. The example prompts and answers are written for the exercise; they are not captured AI responses.

Compare a task, not a brand name

Features, models and account permissions change. This page provides an evaluation procedure rather than a current product ranking. Record the actual product, account type, model if shown, enabled tools, test date and exact task. A result from one setup does not establish every setup's behavior.

Use the same fictional data and output contract for every assistant. The weekly sales example supplies a known answer without exposing private business records.

Give each assistant the same specification

State that each row is an order line, that one all-field repeat is deliberately accidental, and that the report covers Shipped lines from 26 October through before 2 November 2026. Require separate line and distinct-order counts. Keep the input, prompt and any follow-up correction with the result.

Score before changing the prompt

Apply the same quality gate to each first attempt. If a correction is allowed, give comparable correction information and include the time. Record a tool's inability to read a file or execute a formula rather than silently doing that step yourself without accounting for it.

Separate a helpful explanation from a completed calculation. An assistant may produce useful reasoning while still failing the required output.

Report only what you measured

Keep failed attempts and repeat with the second source file. Publish a ranking only after actual tests, and scope it to those versions, inputs and criteria. Do not infer accuracy from the length or confidence of an answer.

No comparative assistant runs were performed for this article. The downloadable log is for your own observations; it is not an empty claim of a completed benchmark.
