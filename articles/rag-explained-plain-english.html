RAG explained with a policy retrieval failure

Follow a fictional source from search result to answer, including an archived rule and an unrelated opening time.

Maintained by ShawnUpdated November 13, 20262 min read

Fictional practice case. The example prompts and answers are written for the exercise; they are not captured AI responses.

Retrieval and generation are separate steps

Retrieval-augmented generation supplies retrieved material to a model as context for an answer. It can make a source available that was not already in the conversation. The retrieved item still needs the right scope, date and permissions.

Use the three-document policy pack ↓

Imagine a search for office opening time returns P1 and P3. P1 is archived; P3 concerns the cafeteria. An assistant can cite both faithfully and still answer the visitor-access question incorrectly.

Trace the failure through the system

StageFailure in this caseObservable check
Source collectionP1 remains searchableKeep archived status and effective dates
RetrievalP2 not selectedCheck retrieved source IDs
AnswerCafeteria time becomes access permissionCompare each claim with source scope
ReviewCitation treated as proofOpen the cited passage and inspect exceptions

The correct ordinary-visitor window for the supplied question date is 10:00–16:00 with a named host. The maintenance exception is conditional. A weekend answer remains unresolved because the pack does not contain that rule.

Test a small set of different questions

Use one question answered directly by P2, one requiring its exception, one where P1 conflicts, and one with no answer in the pack. Record which passages were retrieved, not just the final wording. That separates a retrieval miss from a generation error.

Do not solve a missing-source problem by asking the assistant to be more confident. Correct the source collection or retrieval conditions, then rerun the same cases. Preserve a failed attempt so the change can be assessed.

Keep access controls with the documents

A real deployment also needs to preserve who may retrieve each source. This fictional pack is public teaching data and tests no permissions. It cannot certify a workplace search system. For a small one-off task, manually supplying the correct current excerpt may be enough.
