Prompting

Specify the row meaning before asking for a spreadsheet formula

Show why “one row is an order line” changes the duplicate rule and the expected report.

Maintained by ShawnUpdated November 13, 20262 min read

Fictional practice case. The example prompts and answers are written for the exercise; they are not captured AI responses.

The same words can hide different data models

“Analyze my orders” leaves open whether each row is an order, an item in an order or a status event. In the fictional sales export, order 000101 has a notebook line and a pen line. Their line IDs differ. Both belong in the report.

Removing repeated order IDs would discard a legitimate RM9.60 pen line if the notebook row is kept first. Asking for a shorter formula cannot resolve that missing specification.

Write a task contract

FieldSpecification for this sample
Row meaningOne order line
Identityorder_id plus line_id; exact repeated source record investigated separately
DatesStart inclusive; end exclusive
Eligible statusExactly Shipped
MoneyQuantity × price minus one line discount
ChecksNine included lines, eight orders, RM267.60

An authored request can ask an assistant to explain this contract and propose a formula. It should also list required input types and unresolved assumptions before calculating.

Include a case that breaks the easy answer

The two-line order exposes the danger of deduplicating by order_id. The exact repeated 000103/1 record exposes the opposite danger of keeping a known accidental repeat. Keep both examples in a test set because they require different decisions.

Ask for the method's effect on those records. Then inspect the actual output. A statement that “duplicates are handled” is too vague to establish whether the right rows survived.

Judge the result after applying it

Record the prompt, generated formula, input types, output and corrections. A plausible formula is only a candidate until it runs against the known sample. Do not claim a model benchmark from these authored examples.

The practical work of prompt design here is making the task and failure cases explicit. Once those are clear, a deterministic formula may be sufficient.
