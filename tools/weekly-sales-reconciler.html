How to use this tool

Use a line-item CSV with order_id, line_id, order_date, sku, quantity, unit_price_rm, discount_rm, and status columns. Extra columns are retained in the source-record audit. Set an inclusive start date, an exclusive end date, and the verified source date convention. The eligible status is exactly Shipped.

Choose whether to remove all-field exact repeats only after confirming the source's row meaning. The sample loader enables removal because the fictional source deliberately contains one accidental repeated record. A conflicting order-plus-line key or an invalid required value makes the total unavailable until resolved.

Amounts use a decimal point, an optional RM prefix, and correctly grouped comma thousands separators. Prices and discounts are non-negative with at most two decimal places. Quantities are positive whole numbers. Discounts apply once per line. Refunds, returns, taxes, fees, and currency conversion are outside this tool's scope.

Check the built-in sample

Load the sample: 14 records reconcile to nine included lines, one exact repeat removed, two outside the date window, and two with other statuses. The result is RM267.60, 26 units, and eight orders.

Limits and the downloaded report

The parser supports comma, semicolon, and tab delimiters, quoted separators, escaped quotes, and multiline fields. It reads UTF-8 text, with an optional byte-order mark. An unclosed quote or an invalid field boundary stops processing. Large files should be handled in an appropriate local spreadsheet or data application.

Data remains in memory until you clear or leave the page. The tool does not save it to browser storage. Reports retain unresolved findings. Formula-like text is prefixed with an apostrophe in downloaded review reports; this is a deliberate report-only change. CSV does not define text column types, so import identifiers as Text.
